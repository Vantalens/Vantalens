## 项目

### [Trans2Former](https://github.com/Vantalens/Trans2Former)

本地优先的文档转换工具，支持 23 种输入格式和 16 种输出格式。内置 PP-OCRv5，并通过规则比对、视觉比对和 OCR 回读生成转换质量报告。

`JavaScript` · `Tauri` · `Web Worker` · `WASM`

- **[VantalensWeb / TalentWriter](https://github.com/Vantalens/VantalensWeb)** 用 Hugo 构建个人博客，配套的 Go 写作工具管理发布、评论审核和 SQLite 数据同步。
- **[BiliManga](https://github.com/Vantalens/BilibiliManga)** 用 Rust、Tauri 和 React 开发的第三方 Windows 漫画阅读器，提供本地书库、进度保存和图片缓存，用系统密钥环保护凭据。

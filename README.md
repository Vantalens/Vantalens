## 近期项目

### Trans2Former

Trans2Former 是我近期主要构建的项目，目标是实现一个浏览器端文档转换与重构引擎。

项目基于统一的 `DocumentModel`，对不同格式的文档内容进行解析、转换和结构化处理，尝试将非结构化或半结构化内容转化为更容易处理、展示和复用的数据形式。

主要关注点：

- 文档解析与内容转换
- 统一数据模型设计
- 结构化内容表达
- 前端侧处理能力
- 工程化项目组织

这个项目也是我对“表达”与“实现”关系的一次实践：不仅关注功能是否完成，也关注数据结构、模块边界和系统可扩展性。

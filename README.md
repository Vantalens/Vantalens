## 核心项目

### Trans2Former

Trans2Former 是一个浏览器端文档转换与重构引擎，目标是围绕统一的 `DocumentModel`，对不同来源和格式的文档内容进行解析、转换、结构化表达与复用。

项目关注如何将非结构化或半结构化内容转换为更稳定、可处理、可展示的数据结构，并在前端环境中完成文档解析、内容重构与模型抽象。

主要关注点：

- 文档解析与内容转换
- 统一数据模型设计
- 半结构化内容的结构化表达
- 前端侧处理能力与浏览器运行边界
- 模块划分、数据流组织与工程化维护

该项目是我对“表达模型”与“工程实现”之间关系的一次实践，重点关注数据结构设计、模块边界与系统可扩展性。
